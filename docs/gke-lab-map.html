One environment, end to end

A session: what comes and goes

./startup <env>

  1. Checks that the certificate is ACTIVE and chat-data exists. If not, it stops before building anything.
  2. Plans the cluster and goes on only if the plan just adds.
  3. Applies it: network, Cloud NAT, cluster, three pools (about 12 minutes).
  4. ./bootstrap installs Argo CD.
  5. Argo CD installs the apps from GitHub; it waits until every app is Synced and Healthy.
  6. Waits for the page to answer 200 over HTTPS.

./teardown <env>

  1. Asks you to type the environment's name again.
  2. Deletes the root app: Argo CD removes the apps, the model disk and the load balancer.
  3. Waits until no forwarding rules are left, so no load balancer is orphaned and still billing.
  4. Destroys the cluster (about 10 minutes).
  5. Checks that no disk is left behind except chat-data.
