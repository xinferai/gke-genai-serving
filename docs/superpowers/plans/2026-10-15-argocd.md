# Argo CD for the GKE lab: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Argo CD installs and keeps running the chat app (Open WebUI, Ollama, and its public entrance) from this
repository on GitHub, after a one-command bootstrap.

**Architecture:** `./tf apply` builds the cloud as today. `./bootstrap` installs Argo CD with Helm, creates the
repository secret from a deploy key file on Sam's Mac, and applies one root app; the root app creates two child apps,
`chat` (the open-webui chart with `apps/chat/values.yaml` from git) and `chat-edge` (`apps/chat/edge.yaml`). A new
`./check` script runs every offline check (chart renders, schema checks, field rules, a stand-in run of `bootstrap`,
README consistency) without a cluster.

**Tech Stack:** Argo CD 3.5.5 (Helm chart `argo-cd` 10.10.5), Helm 4.3.0, kubectl 1.37.1, bash 5, yq, kubeconform
(with the public CRDs-catalog schemas), shellcheck.

**Spec:** `docs/superpowers/specs/2026-10-15-argocd-design.md`

## Global Constraints

- Argo CD chart: `argo-cd` **10.10.5** from `https://argoproj.github.io/argo-helm` (Argo CD 3.5.5), release `argocd`, namespace `argocd`.
- Chat chart: `open-webui` **17.0.0** from `https://helm.openwebui.com`, Helm release name **`chat`**, namespace **`chat`**.
- Repository URL, exactly: `git@github.com:xinferai/gke-genai-serving.git`; branch **`main`**.
- Deploy key private half: `~/.ssh/gke-genai-serving-argocd`. Never in git, never in Terraform state, never passed to Helm, never printed.
- Repository secret: `repo-gke-genai-serving` in `argocd`, label `argocd.argoproj.io/secret-type: repository`.
- All three apps: namespace `argocd`, project `default`, automated sync with `prune: true` and `selfHeal: true`, finalizer `resources-finalizer.argocd.argoproj.io`.
- Argo CD settings: `dex` off, `notifications` off, `configs.params."server.insecure": true`, every component on `pool: system`.
- The chat values (`apps/chat/values.yaml`) and `apps/chat/edge.yaml` are not changed by this plan.
- No cluster or cloud actions in this plan: the cluster is down; the live test is Sam's session (spec part 4).
- **Nothing is committed, pushed, or added to GitHub without Sam's word.** This overrides the usual commit-per-task
  habit: tasks end with `./check` passing, and Task 6 hands the commit to Sam.
- Comments match the existing files: plain English, say why, date any finding.

## Adjustments to the spec (made while planning, folded into the spec in Task 6)

- `chat` sets `helm.skipTests: true`, so the Ollama sub-chart's test pod is never deployed, instead of only checking
  for it on the live cluster (the render shows `Pod/chat-ollama-test-connection` without it).
- All three apps get `syncPolicy.retry` (limit 5): automated sync does not try a failed sync again for the same commit
  unless retry is set, so a passing hiccup during the first build would otherwise need a manual sync.
- `chat-edge` also gets `CreateNamespace=true`, so it cannot fail when it arrives before `chat` has made the namespace.
- The spec's "render and compare" and "shellcheck" become one script, `./check`, which also checks the apps' fields and
  runs `bootstrap` against stand-ins.

## Review Focus

1. **The deploy key file is missing** (first run, a new Mac, a typo in the path): `bootstrap` must stop before it
   touches the cluster and print the two commands that make and register the key. Test: Task 4, "no key file".
2. **`bootstrap` is run a second time** (after a failure halfway, or by habit): it must update in place, so no step
   may use a plain `kubectl create`. Test: Task 4, "nothing uses a plain create".
3. **A step fails** (the gcloud login expired, as it did the morning of 2026-10-15, or Argo CD is not ready in 10
   minutes): `bootstrap` must stop and not apply the root app. Test: Task 4, "Helm fails" and "the secret step fails".
4. **A misspelt field in an app** (`selfheal`): the cluster drops unknown fields without an error, so automation
   would quietly be off. Test: Task 3, "a misspelt field in an app is caught" (the strict schema check, proven on a
   copy with a typo).
5. **The private key leaks** into Helm's arguments (and so into its release history) or onto the screen. Test:
   Task 4, "the key never goes to Helm" and "the key's contents never appear in the output".

```bash
#!/usr/bin/env bash
# Offline checks for the lab. Nothing here touches the cluster or Google Cloud; it downloads the two
# Helm charts, and the public schemas for Argo CD, Gateway API and GKE objects.
# Run before every push:   ./check
# Needs helm, yq, kubeconform and shellcheck:   brew install yq kubeconform shellcheck
set -uo pipefail
here="$(cd "$(dirname "$0")" && pwd)"
cd "$here"
tmp="$(mktemp -d)"
trap 'rm -rf "$tmp"' EXIT
failed=0

# check "<what is checked>" <command...>: prints PASS or FAIL, and on a failure the command's output.
check() {
  local what="$1" out
  shift
  if out="$("$@" 2>&1)"; then
    printf 'PASS  %s\n' "$what"
  else
    printf 'FAIL  %s\n' "$what"
    printf '%s\n' "$out" | sed 's/^/      /'
    failed=1
  fi
}

repo=git@github.com:xinferai/gke-genai-serving.git
schemas='https://raw.githubusercontent.com/datreeio/CRDs-catalog/main/{{.Group}}/{{.ResourceKind}}_{{.ResourceAPIVersion}}.json'
# Schema check that also rejects fields the schema does not know (a misspelt field is an error).
strict() { kubeconform -strict -summary -schema-location default -schema-location "$schemas" "$@"; }

# --- The chat app, rendered the way Argo CD renders it (argocd/apps/chat.yaml) ------------------
render_chat() {
  helm template chat open-webui --repo https://helm.openwebui.com --version 17.0.0 \
    -n chat -f apps/chat/values.yaml --skip-tests > "$tmp/chat.yaml"
}
# The names apps/chat/edge.yaml and the NetworkPolicy rely on.
chat_names() {
  local have want
  [ -s "$tmp/chat.yaml" ] || { echo "nothing rendered"; return 1; }
  have="$(yq e '.kind + "/" + .metadata.name' "$tmp/chat.yaml")" || return 1
  for want in Service/chat-open-webui StatefulSet/chat-open-webui Deployment/chat-ollama \
    Service/chat-ollama NetworkPolicy/ollama-only-from-open-webui \
    PersistentVolumeClaim/chat-open-webui PersistentVolumeClaim/chat-ollama; do
    grep -qx "$want" <<< "$have" || { echo "missing $want"; return 1; }
  done
}
check "chat chart renders with apps/chat/values.yaml" render_chat
check "chat objects keep the names edge.yaml and the NetworkPolicy use" chat_names
check "edge.yaml matches its schemas" strict apps/chat/edge.yaml

exit "$failed"
```

```bash
render_argocd() {
  helm template argocd argo-cd --repo https://argoproj.github.io/argo-helm --version 10.10.5 \
    -n argocd -f argocd/values.yaml > "$tmp/argocd.yaml"

workloads='select(.kind == "Deployment" or .kind == "StatefulSet" or .kind == "Job")'
argocd_on_system_pool() {
  local off
  [ -s "$tmp/argocd.yaml" ] || { echo "nothing rendered"; return 1; }
  off="$(yq e "$workloads | select(.spec.template.spec.nodeSelector.pool != \"system\") | .metadata.name" "$tmp/argocd.yaml")" || return 1
  [ -z "$off" ] || { echo "not on the system pool: $off"; return 1; }
}
argocd_unused_parts_off() {
  local names found
  [ -s "$tmp/argocd.yaml" ] || { echo "nothing rendered"; return 1; }
  names="$(yq e "$workloads | .metadata.name" "$tmp/argocd.yaml")" || return 1
  found="$(grep -E 'dex|notifications' <<< "$names")"
  [ -z "$found" ] || { echo "still installed: $found"; return 1; }
}
argocd_requests_set() {
  local missing
  [ -s "$tmp/argocd.yaml" ] || { echo "nothing rendered"; return 1; }

check "Argo CD runs only on the system pool" argocd_on_system_pool
check "Argo CD: single sign-on and notifications not installed" argocd_unused_parts_off
check "Argo CD: every component has resource requests" argocd_requests_set
check "Argo CD screen is plain HTTP behind the port-forward" \
  yq e -e 'select(.kind == "ConfigMap" and .metadata.name == "argocd-cmd-params-cm") | .data["server.insecure"] == "true"' "$tmp/argocd.yaml"
```

```bash
apps=(argocd/root.yaml argocd/apps/chat.yaml argocd/apps/chat-edge.yaml)
check "Argo CD apps match their schemas" strict "${apps[@]}"
# The cluster drops fields it does not know without an error, so a misspelt selfHeal would quietly
# switch self-heal off. The strict schema check catches that; prove it on a copy with a typo.
typo_caught() {
  [ -s argocd/apps/chat-edge.yaml ] || { echo "argocd/apps/chat-edge.yaml missing"; return 1; }
  sed 's/selfHeal/selfheal/' argocd/apps/chat-edge.yaml > "$tmp/typo.yaml"

}
check "a misspelt field in an app is caught" typo_caught
for f in "${apps[@]}"; do
  check "$f: in namespace argocd, project default" \
    yq e -e '.kind == "Application" and .metadata.namespace == "argocd" and .spec.project == "default"' "$f"
```

```yaml
# The root app: keeps every app in argocd/apps/ (on main, on GitHub) running. ./bootstrap applies this
# one file; Argo CD makes the rest from git. Deleting it removes everything the apps made (the
# finalizer), which is how a session ends: README, "End of a session".
apiVersion: argoproj.io/v1alpha1
kind: Application
metadata:
  name: root
  namespace: argocd
  finalizers:
    - resources-finalizer.argocd.argoproj.io
spec:
  project: default
  source:
    repoURL: git@github.com:xinferai/gke-genai-serving.git
    targetRevision: main
    path: argocd/apps
  destination:
    server: https://kubernetes.default.svc
    namespace: argocd
  syncPolicy:
    automated:
      prune: true
      selfHeal: true
    # Automated sync does not try a failed sync again for the same commit unless told to.
    retry:
      limit: 5
      backoff: {duration: 30s, factor: 2, maxDuration: 5m}
```

- [ ] **Step 1: Create `test/bootstrap_test.sh`**

```bash
#!/usr/bin/env bash
# Runs ./bootstrap against stand-ins for ./k and ./h that only write down what they were asked to do,
# so its order and its handling of the deploy key are checked without a cluster. Part of ./check.
set -uo pipefail
here="$(cd "$(dirname "$0")/.." && pwd)"
tmp="$(mktemp -d)"
trap 'rm -rf "$tmp"' EXIT
failed=0

# expect "<what>" <command...>: prints ok or FAIL.
expect() {
  local what="$1"
  shift
  if "$@"; then printf 'ok    %s\n' "$what"; else printf 'FAIL  %s\n' "$what"; failed=1; fi
}

# The stand-in: writes one line per call to $LOG; fails on purpose when its arguments contain
# $FAIL_ON; plays its part in the secret pipeline (create --dry-run | label --local | apply -f -).
cat > "$tmp/stand-in" <<'EOF'
#!/usr/bin/env bash
echo "$(basename "$0") $*" >> "$LOG"
if [ -n "${FAIL_ON:-}" ] && [[ "$*" == *"$FAIL_ON"* ]]; then exit 1; fi
case "$*" in
  *--dry-run=client*) echo "kind: Secret" ;;
  *--local*) cat ;;
  *"apply -f -"*) cat > /dev/null ;;
esac
exit 0
EOF
chmod +x "$tmp/stand-in"
ln -s "$tmp/stand-in" "$tmp/k"
ln -s "$tmp/stand-in" "$tmp/h"
echo "MARKER-not-a-real-key" > "$tmp/key"

# run <name> [VAR=value ...]: runs bootstrap with the stand-ins. Calls go to $tmp/<name>.log,
# output to $tmp/<name>.out, the exit status to $tmp/<name>.status.
run() {
  local name="$1"
  shift
  : > "$tmp/$name.log"
  env LOG="$tmp/$name.log" K="$tmp/k" H="$tmp/h" ARGOCD_DEPLOY_KEY="$tmp/key" "$@" \
    "$here/bootstrap" > "$tmp/$name.out" 2>&1
  echo $? > "$tmp/$name.status"
}
succeeded() { grep -qx 0 "$tmp/$1.status"; }

installs_argocd_first() {
  local first
  first="$(head -1 "$tmp/good.log")"
  [[ "$first" == "h upgrade --install argocd argo-cd "* && "$first" == *" --version 10.10.5 "* \
    && "$first" == *" -f $here/argocd/values.yaml "* && "$first" == *" --wait"* ]]
}
secret_made_and_applied() {
  grep -qxF -- "k -n argocd create secret generic repo-gke-genai-serving --from-literal=type=git --from-literal=url=git@github.com:xinferai/gke-genai-serving.git --from-file=sshPrivateKey=$tmp/key --dry-run=client -o yaml" "$tmp/good.log" \
    && grep -qxF -- "k label --local -f - argocd.argoproj.io/secret-type=repository -o yaml" "$tmp/good.log" \
    && grep -qxF -- "k apply -f -" "$tmp/good.log"
}
# (Each picks its lines into a file first: grep -q in a pipe can end the pipe early, and with
# pipefail that can turn a real match into a pass.)
no_plain_create() {
  grep -E '^k .* create ' "$tmp/good.log" > "$tmp/creates" || true
  ! grep -vqF -- '--dry-run=client' "$tmp/creates"
}
root_applied_last() { [ "$(tail -1 "$tmp/good.log")" = "k apply -f $here/argocd/root.yaml" ]; }
key_kept_from_helm() {
  grep '^h ' "$tmp/good.log" > "$tmp/helm-calls" || true
  ! grep -qF -e "$tmp/key" -e MARKER "$tmp/helm-calls"
}
key_not_shown() { ! grep -q MARKER "$tmp/good.out"; }
stops_without_key() { ! succeeded nokey && [ ! -s "$tmp/nokey.log" ]; }
says_how_to_make_key() { grep -q 'ssh-keygen' "$tmp/nokey.out" && grep -q 'gh repo deploy-key add' "$tmp/nokey.out"; }
```

```bash
#!/usr/bin/env bash
# Hands a new lab cluster to Argo CD. Run once after ./tf apply; running it again is safe.
#   ./bootstrap
# 1. Installs Argo CD with Helm (chart argo-cd 10.10.5, which is Argo CD 3.5.5), settings in
#    argocd/values.yaml, and waits until it is ready.
# 2. Gives it read access to this private repository with the deploy key on this Mac. The key goes
#    straight from its file into a Kubernetes Secret: never into git, Terraform state, or Helm
#    (which would copy it into every release revision).
# 3. Applies the root app (argocd/root.yaml). Argo CD then installs everything else from GitHub,
#    branch main: push first, or it installs what was there before.
# Design: docs/superpowers/specs/2026-10-15-argocd-design.md
set -euo pipefail
here="$(cd "$(dirname "$0")" && pwd)"
# K and H can name stand-ins for ./k and ./h; test/bootstrap_test.sh uses that to run this
# without a cluster.
k="${K:-$here/k}"
h="${H:-$here/h}"
key="${ARGOCD_DEPLOY_KEY:-$HOME/.ssh/gke-genai-serving-argocd}"
repo=git@github.com:xinferai/gke-genai-serving.git

if [ ! -s "$key" ]; then
  cat >&2 <<EOF
No deploy key at $key. Make it once on this Mac, then add its public half to GitHub (read-only):
  ssh-keygen -t ed25519 -N '' -C 'argocd-lab read-only deploy key' -f $key
  gh repo deploy-key add $key.pub --repo xinferai/gke-genai-serving --title "argocd-lab (read-only)"
EOF
  exit 1
fi

"$h" upgrade --install argocd argo-cd --repo https://argoproj.github.io/argo-helm --version 10.10.5 \
  -n argocd --create-namespace -f "$here/argocd/values.yaml" --wait --timeout 10m

# Made locally and applied, so a second run updates the secret instead of failing on it.
"$k" -n argocd create secret generic repo-gke-genai-serving \
  --from-literal=type=git --from-literal=url="$repo" --from-file=sshPrivateKey="$key" \
  --dry-run=client -o yaml |
  "$k" label --local -f - argocd.argoproj.io/secret-type=repository -o yaml |
  "$k" apply -f -

"$k" apply -f "$here/argocd/root.yaml"
echo "Argo CD is installing the apps from GitHub. Watch: ./k -n argocd get applications -w"
```
